# Gestão de acervo digital

Sistema em Python para administração de documentos digitais em bibliotecas universitárias. Os bibliotecários adicionam, renomeiam, removem e listam documentos (PDF, ePUB e outros formatos) por uma interface de linha de comando, com listagem agrupada por tipo de arquivo e por ano de publicação.

Projeto desenvolvido como atividade avaliativa da disciplina Programação para Ciência de Dados, 1º período do Curso Superior de Tecnologia em Inteligência Artificial, PUC-PR.

## Estrutura do repositório

- `src/`: código-fonte do sistema.
- `tests/`: testes automatizados.
- `docs/`: documentação técnica das funcionalidades.
- `acervo/`: diretório de trabalho com os documentos digitais.

## Estado atual

Em desenvolvimento iterativo. As funcionalidades concluídas estão registradas no histórico de commits do repositório.
